# Exact cipher model synthesis

`engine/cipher_synthesis.py` uses the optional Z3 SMT solver to fit cipher equations to aligned plaintext cribs. Install `requirements-synthesis.txt` in the active Python environment to enable it. Importing the module does not load Z3, so the standard-library engine remains usable without that dependency. The [official Z3 Solver API](https://z3prover.github.io/api/html/classz3py_1_1_solver.html) documents solver checks, models, push/pop scopes, and unknown-result reasons.

The finite model set includes affine, Caesar, Vigenere, Beaufort, monoalphabetic substitution, and unknown-alphabet versions of [Quagmire I](https://www.cryptogram.org/downloads/aca.info/ciphers/QuagmireI.pdf), [Quagmire II](https://www.cryptogram.org/downloads/aca.info/ciphers/QuagmireII.pdf), and [Quagmire III](https://www.cryptogram.org/downloads/aca.info/ciphers/QuagmireIII.pdf). Quagmire uses all-different ranks in `0..25` and modular row shifts. Alphabet rotation is normalized by placing `A` at rank zero; this removes equivalent representations without excluding mappings. These are arbitrary permutation alphabets; synthesis does not constrain keyword length or invent keyword words. The reported indicator under `A` is one equivalent example row setting.

A layout acts first on original plaintext positions. Identity, reversal, and specified columnar widths are available. Columnar layouts fill rows and take columns left to right, with no padding. The letter cipher then uses the permuted stream, including its period positions. Crib offsets and every plaintext prediction remain in original plaintext coordinates.

Each family, period, and layout receives `sat`, `unsat`, or `unknown`. A satisfying model returns example parameters, explicitly labeled as examples. For each unsupplied position, the solver asks whether that plaintext letter could differ from the example. `unsat` for that alternate-value query proves the letter is forced within that model class. `sat` leaves it ambiguous, and `unknown` leaves its forcedness unresolved.

Aggregate consensus extends beyond supplied cribs only after every requested class and all consensus checks finish. A letter then must be forced to the same value in every satisfiable class. Any timeout, unresolved query, or check-budget exhaustion reduces aggregate output to the supplied crib letters. All-unsatisfiable results also retain only the cribs. `claimed_plaintext` stays null.

The defaults test four families, periods up to 4, identity and reverse layouts, 10,000 solver checks, and a five-second global monotonic deadline. Caps are 512 letters, 128 periods, 1,024 model classes, 100,000 checks, and 60 seconds. Each native solver call receives the remaining deadline in milliseconds. Model construction and Python bookkeeping also consume that deadline; their input sizes are bounded. Native timeout handling and operating-system scheduling can add small return overhead. The report preserves actual elapsed time, all class statuses, bounds, and unresolved counts.

The certificate is a synthetic affine-after-reversal example. Six supplied plaintext letters constrain a 25-letter result, checked by SHA-256. Tests also cover Vigenere-after-reversal, a columnar composition, sparse unknown Quagmire alphabets, incompatible equations, injected solver unknown, and exact check-budget exhaustion. These checks establish conditional results within stated models, with no historical decryption or unsolved-text claim.
