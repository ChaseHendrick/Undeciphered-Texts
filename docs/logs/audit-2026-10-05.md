# Audit of the 5 October Bob and solver commits

5 October 2026. Not a reading. No letter string is stored.

## Main was red

The last three code commits on `main` (`f1bfedb`, `6bcb64c`, `f63a38d`) each added three frozen files to `engine/data/swarm_cache`, 72 to 81, and did not update three pinned checks. CI runs 133, 134 and 135 of `check.yml` failed on both jobs. The failures were:

- `tests/test_dagapeyeff_checks.py` still expected 72 frozen files.
- `docs/logs/swarm-board-2026-10-04.md` still said 72, so the board page no longer matched `board_text()`.
- The `checks` entry of the provenance chain, and so the chain hash, had moved.

The board page was regenerated, the count updated, and the chain pins rewritten. The nine new frozen reports were also added to the chain, which had skipped them. `tests/test_dagapeyeff_cache.py` now fails with a named list when a frozen file has no search behind it or is missing from the chain.

## The frozen files were never rerun by a test

Each `@frozen` report is read from its file after the first run, so its unit test reads the stored numbers and never runs the search. A code change that would move a score could not fail a test. `tools/verify_cache.py` reruns every frozen search in its own process and compares the result with the file, key by key. It never rewrites a file.

The full run on this machine took about 40 minutes with three jobs. 80 of 81 files reproduced exactly. The slowest were `word` (289 s), `placed` (238 s), `columns` (220 s) and `patterns` (199 s).

The one mismatch was `router-swarm`: the file says the router names substitution at 0.9696, and the rerun says 0.969. That file was written at 18:55 on 4 October. The warm start promoted at 20:09 the same day replaced the weight file. Every other field reproduces: 40 of 40 shuffles are named substitution, 25 of 40 are at least as confident, and the fourth column is 6 of 200. The file was refreshed and the change is appended to `engine/data/corrections.json` as `router-confidence-used-old-weights`. The refusal stands.

## The substitution drill missed because of the model

`engine.solver_train` found the default substitution search exact on 0 of 6 windows of 200 letters, and more steps did not help. `engine.solver_model` sorts every miss. If the returned key scores at least as well as the true text, the language model preferred the wrong key and more steps cannot fix it.

The default quadgram model is fit on 8,689 letters. `engine.language.get_large_model` fits the same model on the 1,916,398 public-domain letters already in the repo, which exclude the Doyle, Wells and Grimm held-out windows. Eight held-out Doyle windows per length, each with its own permutation:

| Arm | Width | At least 9 in 10 letters right | Exact | Letters right | Misses the model prefers | Misses the search left |
| --- | --- | --- | --- | --- | --- | --- |
| small model, 10 restarts, temperature 30 | 100 | 1 of 8 | 0 | 0.5787 | 5 | 2 |
| large model, 30 restarts, temperature 10 | 100 | 7 of 8 | 5 | 0.935 | 0 | 1 |
| small model, 10 restarts, temperature 30 | 200 | 5 of 8 | 0 | 0.8337 | 2 | 1 |
| large model, 30 restarts, temperature 10 | 200 | 8 of 8 | 6 | 0.9981 | 0 | 0 |

The large model is opt-in, `solve_substitution(..., model=get_large_model())` or `python3 -m engine solve substitution TEXT --model large --restarts 30 --temperature 10`, so every frozen score keeps its meaning. At 60 and 80 letters the large arm was still mostly wrong in a scratch run. Exact recovery also fails on letters that appear once, such as a B and P swap.

## Two guards let a plaintext through

`engine.bob_scratch.write_note` refused twenty letters in a row, but a sentence with spaces, a list, or a nested dictionary passed. It now strips spaces and punctuation before the check and walks lists and dictionaries. The `sha256` field is checked as hex instead.

`engine.solver_judge.judge_claim` blocked `solved` only when it was `True`, and a plaintext only when it was a non-empty string. `solved` set to `"yes"` or `1`, or a plaintext stored as a list or a dictionary, was accepted. Any `solved` value other than `False` or a missing flag is now a solved claim, and any non-empty plaintext of any type is blocked.

## A network test failed offline

`tests/test_known_language_reader.py` downloads its cited phrases. Behind a proxy that refuses those hosts, it raised four errors. A failed download now skips that language with the URL and the error. The German checks that need no download still run.
