## Failed search on Nr. 86

Ciphertext (46 letters, designator included; the form’s length 46 counts `FBOIQ`): `FBOIQPMWRLVNREKEXXMBRWMAMRUIHEHCSHERBUZIIMLOUQ`.

Keyspace: two independent 5×5 squares on a 25-letter alphabet (no J). About `25! × 25! / 3000` distinct keys (mcts.pdf).

Neighborhood actually searched: random restarts, then strict hill-climbing by every pairwise letter swap inside each square. About 15–20 seconds per target on one core (~9k–50k local optima). Scorer: conditional trigram log-likelihood fit on Project Gutenberg eBook 77905 (*Deutsche Märchen*), umlauts folded, `ch→Q`, `j→II`, non-letters written as `X`.

The 200-letter control, whose true plaintext scores −1.81 per trigram, never got better than −3.52. The same search therefore does not find a known two-square key of that length. Nr. 86 is only 46 letters, under the paper’s ~49-letter unicity distance, so a fairy-tale-like string can outscore authentic military plaintext (about −3.3 per trigram on this model).

Unverified candidate, not a claim: `RITXDENXGOLDSXSEINEIMXWIEFXERXKNUREQTTXDASXWAQ`, score −75.86 (−1.724 per trigram), squares `KQRODNWEIPGMSUHCABXYLZFTV` / `QCHFWEDXMGKYRSTUZNILAVOBP`. It is not a claim because (1) no published plaintext was fetched to match it, (2) the same climber misses a longer known example whose true score is better than this candidate’s military-text peers, (3) −1.72 matches the fairy-tale corpus, not the −3.3 of published TS plaintext.
