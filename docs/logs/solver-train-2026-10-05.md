# A longer substitution search, 5 October 2026

The default search is 4000 steps and 10 restarts. The longer search is 8000 steps and 16 restarts. Six fresh windows of 200 training letters were encrypted with one fixed permutation. Those windows are not the pentest windows.

The default search is exact on 0 of 6. The longer search is exact on 0 of 6. Extra steps did not recover those windows.

The known substitution certificate is 620 letters with the same permutation. Both searches recover it. The longer search is not broken, and it is not better on the short windows. The solver's default arguments stay. This is not a reading.
