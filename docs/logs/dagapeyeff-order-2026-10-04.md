# Why a substitution of these cells is not a reading

4 October 2026. 45,000 reorderings. No letter string is stored.

The score is how strongly one symbol predicts the next. Renaming the symbols does not change it: the same English passage, letters shifted by seven places, scores 1.0658 either way. So a substitution cipher can only be as prose-like as the order already is. If the order is weak, no alphabet makes it prose.

The 196 cells in printed order score 0.5706. 4,164 of 5,000 random orders of those same cells score at least that high. The printed order is a weak one.

| Order | Score |
| --- | --- |
| Printed | 0.5706 |
| Straight down the columns | 0.6684 |
| Best of 20,000 across-keys | 0.7657 |
| Best of 20,000 down-keys | 0.7141 |
| Best of 5,000 fully random orders | 0.7556 |
| English prose, 196 letters | 1.0658 |
| German prose, 196 letters | 1.2000 |
| The book's solved exercise, 92 letters | 1.5282 |

The short exercise scores higher because a short text inflates this measure. The fair comparison is the 196-letter prose. The best column key in 20,000 is 0.7657, which is about where the luckiest random orders already are, and it is well below both prose passages. Column keys are not finding an order the random orders cannot find, and none of the orders found here is prose.

A substitution of the printed cells is therefore not a reading in English or in German. A substitution after one of these column keys is not one either. This search did not try every possible order of 196 cells. It did try every chance a short column key has, forty-five thousand times.
