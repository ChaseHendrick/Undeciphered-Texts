# Spirals, snakes and zigzags on the cells, 5 October 2026

Earlier passes tried column keys, rails, straight diagonals and regular deletions. This pass tries the other classical routes on a 14 by 14 square: a spiral from each corner turning either way, a snake along rows or columns from each side, and a zigzag along the diagonals from each corner. Reversed routes are dropped as duplicates, which leaves 16. Each is read two ways, as the path the plaintext was written along and as the path the rows were copied out along. That is 32 readings.

The score is successive-symbol information, which no letter key can change. The printed order scores 0.5706. The best reading is a spiral, copied out, at 0.686. Shuffled cells given the same 32 readings do at least as well 567 times in 2,000. English of the same length scores 1.0658.

No route stands out. Not a reading. No letter string is stored.
