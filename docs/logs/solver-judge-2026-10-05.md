# A judge in front of a solver claim

5 October 2026. No letter string is stored.

`engine.solver_judge` does not search. A claim with solved set, a stored plaintext, a non-finite score, or a failed re-encryption is blocked. The plaintext is not copied out. A historical name cannot leave this judge marked solved. That list includes K4, the 1939 challenge, Voynich, Beale, Zodiac, and the undeciphered scripts already kept out of the catalog's solved column.

Caesar, Vigenere, and Beaufort have a forward check. A match means the key rebuilds the ciphertext. It does not mean an unsolved text was read. Other families return no forward answer from this judge rather than a guessed match.
