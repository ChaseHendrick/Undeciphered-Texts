`SOLVERS` registry: `caesar`, `vigenere`, `substitution`. The separate `engine/tool_registry.py` allowlist exposes explicit invocations of supplied-key helpers and bounded searches, with their parameters and modes. Its `required_parameters` field reflects the Python function signature; runtime evidence requirements still apply. For example, Hill inference needs a nonempty crib, and Morse inference needs a lexicon or decoded-text crib. Listing a helper there does not make it a blind solver.

The [persona collection](persona-solvers.md) connects systematic, clue-based,
compositional, conservative, alignment, layout and algebra searches with separate
adversarial and skeptical review. These are working APIs over the same engine,
with recovered-output controls, explicit budgets and unverified result contracts.

incompatible backend score units. Personality flavor cannot supply correctness.
Bob the Neural Net remains a separate family router.
