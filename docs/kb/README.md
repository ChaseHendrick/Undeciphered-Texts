# Knowledge base

Index of claims already written up under `docs/` with a URL. This file does not add decipherments. If a cell and a source disagree, the source wins.

**Novelty** uses the labels in [../NOVELTY.md](../NOVELTY.md): Sourced fact, Specialist consensus, Live hypothesis, Contested, Engine result, Not a decipherment. Untested ideas are not indexed.

Corpus figures are edition-dependent. They are copied from the linked note, not averaged.
